# Hybrid-MLE-PSO-Rayleigh-Poisson

# Hybrid MLE-APSO for Rayleigh-Poisson Distribution
### An Application to Wind Turbine Reliability Assessment

This repository contains the complete R code for reproducing all
simulations, analyses, and results presented in the paper:

> **Adaptive Hybrid Likelihood Optimization for Rayleigh-Poisson Reliability Modeling**
> Alaa Fallah Hasan and Maryam Sharafi
> *Quality and Reliability Engineering International*
